# Roadmap

## Stage 1

1. Today dashboard and explainable recommendations
2. Authentication and profile onboarding
3. Goal, category, and task management
4. Focus timer and five-minute start
5. Daily/weekly reviews, reminders, and responsive calendar
6. End-to-end accessibility and deployment validation

## Later—not part of Stage 1

Calendar provider synchronization, native apps, teams, habits, deeper analytics, and opt-in AI planning. These should only be added after daily-start and daily-review usage demonstrate value.
